# Lab 1: Java Maven Starter Project

A Java project demonstrating database connectivity using JDBC and MySQL.

## Technologies
- Java
- JDBC
- MySQL
- Maven

## Database
- **Name:** `StudentsDB`
- **Status:** Database created; table not yet created.

## Setup
1. Clone this repository.
2. Configure your MySQL connection credentials.
3. Reload Maven dependencies in IntelliJ IDEA.
4. Run `StudentDatabaseOperations.java`.
